# Publication checklist

- This 20261020 release supersedes the 20261018 source-only ZIP.
- Upload the contents of the release folder, including `research_data/`.
- The newly built public database contains research data, not operational accounts.
- Never add private runtime study directories or original Git history.
- Run `python3 tools/verify_public_data.py` after downloading.
- Record the repository URL and release commit in the manuscript and response letter.
- Manuscript data-availability statements saying no corpus/responses/ratings are
  distributed are superseded and must be updated before submission.
- Choose and verify applicable code/data licensing before claiming an open-source
  or unrestricted third-party-data license. LICENSE_NOTICE.md grants no new license.
